# ResNei SDD

The ResNei **Software / Solution Design Document** and the figures it references.

- [`resnei.md`](resnei.md) — the full design document for ResNei ("Research
  Neighbourhood"), an AI-augmented environment for discovering, analysing, and
  connecting ideas over the Discovery Engine knowledge graph (Version 1.0, May 2025,
  DOI 10.5281/zenodo.15389683). Read this first.
- `images/` — diagrams embedded by `resnei.md` (edges-nodes, pairwise score, and
  numbered figures).

The document describes the design and research direction. The early prototype it
refers to lives in [`../resnei/`](../resnei/README.md); capabilities described here
are design targets unless that code demonstrates them. The Discovery Engine system
series is indexed in [`../Docs/README.md`](../Docs/README.md).
